## 执行语义

每次点击执行启动独立进程和数据库会话。同次执行共享临时表、变量和事务，下一次执行不会复用该会话。发生连接故障时不自动重放写语句。

MySQL、PostgreSQL、SQLite 按完整语句执行并在错误后停止。SQL Server 保留原生批次语义：GO 分批、批次内支持 DECLARE，开启 XACT_ABORT；某批次失败后不再执行后续批次，批次内部的错误处理遵循 SQL Server。

事务必须在同次执行中包括 BEGIN / COMMIT。执行结束但未提交时回滚并显示提示。取消不会撤销已经提交的语句，写入响应不确定时需核实状态。

MySQL/PG 的取消使用独立控制连接发送 KILL QUERY / pg_cancel_backend；SQL Server 取消当前 request。SQLite 的同步原生调用放入可终止进程，避免长查询阻塞 Electron 主进程。取消以执行 ID 和所属窗口匹配，不能误停其他执行。

默认超时 5 分钟，支持 30 秒、1 分钟和不限时。SQL 分句支持字符串、注释、引用标识符、MySQL DELIMITER、PostgreSQL dollar quote 和 SQLite trigger；不支持脚本内切换非默认 SQL 词法模式和 GO 次数展开。

## 查询结果交互（2026-09-16）

- 单击、拖动或 Shift + 方向键选择矩形区域；⌘/Ctrl + A 选中当前筛选结果，⌘/Ctrl + C 复制 TSV，可选择携带列名。右键保留单元格原值、整行 TSV / JSON 复制。
- 双击单元格或选中后按 Enter 打开详情侧栏，查看完整文本、格式化 JSON 和复制原值。
- 拖动列边缘调整宽度，双击边缘按样本内容自适应；列设置支持隐藏列、固定到左侧，至少保留一列。
- 点击列头循环升序、降序、取消排序。搜索和按列“包含”筛选只作用于当前已加载结果，不重新查询数据库。
- CSV 导出当前筛选后的全部行、可见列和排序顺序，使用标准双引号转义、CRLF、UTF-8 BOM。NULL 和空字符串导出均为空字段，表格中分别标记。
- 结果最大化收起 SQL 编辑器，恢复时回到原面板比例。同一次执行内切换结果或日志保留各结果的操作状态；重新执行后重置。
- 修复较大结果的最后一条 IPC 完成消息未排空即断开，导致查询成功却误报“执行进程退出”的问题。

验证：新增 CSV / TSV / 原值 / 排序 / 选区 5 项单元测试，以及 5000 行长字段的执行完成回归测试；本地 SQLite UI 检查覆盖搜索、筛选、复制、详情、固定/隐藏列、列宽和最大化。远程数据库集成测试需要显式提供测试连接环境变量。

### 选区复制格式

工具栏“复制为…”与右键菜单支持选区 JSON 和 INSERT；原有复制按钮与快捷键仍复制 TSV。JSON 使用选中列名作为键，保留 NULL、布尔值和数字，BigInt 转为字符串避免精度损失。INSERT 支持四种 SQL 数据库语法，要求填写目标表名，可单独指定 Schema / 数据库；先预览再复制，不自动执行。表名、列名和字符串按方言转义，重复列名和不安全整数会提示而非静默生成错误语句。

补充验证：JSON / 方言转义等单元测试及 SQLite INSERT 实际写入再读取的回归测试通过；UI 实测两行两列选区 JSON 与含单引号中文的 INSERT 剪贴板输出。
