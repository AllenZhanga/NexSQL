## 执行语义

每次点击执行启动独立进程和数据库会话。同次执行共享临时表、变量和事务，下一次执行不会复用该会话。发生连接故障时不自动重放写语句。

MySQL、PostgreSQL、SQLite 按完整语句执行，单条报错后记录错误并继续执行后面的语句。SQL Server 保留原生批次语义：GO 分批、批次内支持 DECLARE，开启 XACT_ABORT；某批次失败后继续执行后续批次，批次内部的错误处理遵循 SQL Server。存在失败时保留总体 failed 状态，并返回 failedStatements 数量，界面显示“执行结束 · N 处错误”；每条错误仍出现在对应结果和日志中。

继续执行不改变显式事务语义。PostgreSQL 事务发生错误后，后续普通语句可能继续报事务已中止，直到脚本执行 ROLLBACK 或 ROLLBACK TO SAVEPOINT。SQLite / MySQL 的事务可能继续有效，脚本里的 COMMIT 仍会执行；应用不自动回滚单条错误或跳过用户的 COMMIT。取消和超时仍停止后续语句，不会自动重连或重放连接故障期间的写入。

事务必须在同次执行中包括 BEGIN / COMMIT。执行结束但未提交时回滚并显示提示。取消不会撤销已经提交的语句，写入响应不确定时需核实状态。

MySQL/PG 的取消使用独立控制连接发送 KILL QUERY / pg_cancel_backend；SQL Server 取消当前 request。SQLite 的同步原生调用放入可终止进程，避免长查询阻塞 Electron 主进程。取消以执行 ID 和所属窗口匹配，不能误停其他执行。

默认超时 5 分钟，支持 30 秒、1 分钟和不限时。SQL 分句支持字符串、注释、引用标识符、MySQL DELIMITER、PostgreSQL dollar quote 和 SQLite trigger；不支持脚本内切换非默认 SQL 词法模式和 GO 次数展开。

## SQL 文件导入导出与表数据快捷键（2026-10-14）

核查发现原数据库概览导入使用简单分号拆分且逐条调用普通查询，事务与会话上下文无法可靠保留；原表导出也存在目标数据库与数据读取不一致、DDL 缺少结束分号的问题。

- 侧栏表节点和数据库概览的表清单行新增右键“导出表（SQL 文件）”“导入表（SQL 文件）”。数据库概览顶部导出按勾选表导出，未勾选时导出当前数据库全部对象。
- 导出统一支持仅结构、仅数据、结构和数据。数据读取使用指定数据库的独立执行会话，DDL 标准化结束分号。SQL 字面值正确处理单引号、反斜杠、Unicode、NULL、布尔值和二进制；不安全整数会显式报错。
- SQL 文件导入支持 UTF-8 / BOM，最大 50 MB；预览前 5 条语句、显示目标数据库及总条数，再一次性执行原始脚本。复用方言解析器，支持 MySQL DELIMITER、PostgreSQL dollar quote、SQL Server GO、SQLite trigger。同一脚本共享会话，报错后继续并展示错误日志，可停止导入；结果明确展示事务回滚与取消提示。为避免重复写入，同一导入结果不能直接再次提交，需重新选择文件。
- SQL 文件中的表名和数据库切换语句以原始文件为准，右键所点的表不会自动替换文件里的表名。导入完成后刷新当前表清单和侧栏 Schema。
- CSV 当前页与筛选结果导出保留原有功能；修复 CR 转义、增加 UTF-8 BOM，并延迟释放下载 URL。筛选结果导出增加查询错误处理和数据库隔离。
- 表数据页增加快捷键提示、刷新按钮；Cmd/Ctrl+R 和 F5 刷新，Cmd/Ctrl+F 聚焦筛选，Cmd/Ctrl+S 或 Cmd/Ctrl+Enter 提交，Cmd/Ctrl+Alt+N 新增草稿行，Cmd/Ctrl+A 选中当前页，Cmd/Ctrl+C 复制 TSV，F2 编辑活动行，Shift+上下键连续选择，Alt+左右键翻页，Delete / Backspace 标记删除，Esc 清空选择/关闭菜单。文字输入框保留常规文本编辑快捷键；提交、刷新可在编辑输入框内使用。刷新保留未提交缓冲区，提交仍走独立事务接口。
- 修复桌面运行时 Cmd/Ctrl+R 被 Electron 默认刷新拦截的问题：主进程把该快捷键转成数据刷新通知，避免整个页面重载。快捷键只响应当前表标签和工作区，不穿透设计表、JSON 或 SQL 导入导出等弹窗。

验证包括导出 SQL 的 SQLite 实际重导入、指定数据库和失败读取的回归测试；隔离 SQLite UI 实测右键 SQL 下载、含中间错误的文件导入、清单刷新、筛选 CSV、输入框内刷新、F2 编辑及 Cmd+S 成功提交。MySQL / PostgreSQL 实库回归测试同时运行。

范围限制：导出是当前表 DDL 和表数据的逻辑 SQL 导出，未覆盖完整数据库备份。PostgreSQL / SQL Server 原有 DDL 主要是字段定义，约束、索引、序列等未完整覆盖，界面已提示；这些数据库的视图定义不生成错误的 CREATE TABLE，而是显式拒绝结构导出。SQLite 的额外索引、触发器也未纳入表 DDL。生成列、依赖外部对象和数据库特有复杂类型需另行核对。大结果仍整体缓存在内存中；SQL Server 未做实库验证。

## 数据库结构按需加载（2026-10-15）

- 连接后只读取数据库名，不再并发读取所有库的表清单。点击库名或展开按钮才加载该库的表，一次只展开一个库。
- 搜索只筛选当前展开库的已加载表；切换库时清空搜索，不扫描或自动展开其他库。未选择库时提示先选择数据库。
- 已加载表清单缓存复用，同一库的并发请求合并；空库也缓存。刷新只更新库名和当前展开库，断开、重连、删除连接时清理缓存，并忽略旧连接的迟到响应。失败可在原位置重试。
- SQL 编辑器只读取当前选择库的表名，字段按 SQL 中引用的表加载，取消批量预取全部表字段。

验证：模拟 100 个库，读取库名时表查询次数为 0，选择一个库后仅查询该库。覆盖缓存、空库、并发去重、乱序响应、刷新、失败重试和断线失效；本轮完整测试 71 项通过，9 项远程数据库集成测试因未配置连接跳过。renderer/main TypeScript 检查及构建通过。隔离 SQLite 预览验证单库展开、切库清空搜索、当前库筛选及缓存复用。

## Navicat 连接导入（2026-10-15）

连接列表顶部“导入连接（NexSQL / Navicat）”打开导入窗口。Navicat 中使用“文件 → 导出连接”生成 `.ncx`（[官方说明](https://help.navicat.com/hc/en-us/articles/218281627-How-to-get-the-connection-information-when-migrating-Navicat-to-new-computer)），选择文件后预览、勾选并导入。原有 NexSQL JSON 同样经过预览流程。支持 UTF-8 / BOM 和带 BOM 的 UTF-16 文件，最大 5 MB、2000 个连接。

- 支持 MySQL、MariaDB（映射 MySQL）、PostgreSQL、SQL Server SQL 认证、SQLite、Redis；迁移名称、主机、端口、数据库、用户名、基础 SSL 开关，以及文件中明确提供的分组名称。Navicat 文件若只有项目 UUID，没有项目名称则提示无法还原分组名称。
- 支持 NCX 常见 AES-128-CBC 密码格式，在主进程本地转换，使用现有密码保存流程写入；预览只返回密码状态，不返回明文。算法依据 [HyperSine 的原始格式分析](https://github.com/HyperSine/how-does-navicat-encrypt-password/blob/master/doc/how-does-navicat-encrypt-password.md)。旧版 Blowfish 或无法转换的密码不会被误当成明文密码保存，连接配置仍可导入并提示补填。
- 不支持的数据库、HTTP 隧道、命名管道、SQLite 加密、Windows 认证、客户端证书或严格证书校验等配置在预览中说明并禁止勾选，不会静默降级为直连。基础 SSL 连接显示验证行为依 NexSQL 实现的提示。SQLite 文件路径需要在当前电脑有效。
- 同名同配置的连接在文件内和现有连接中去重；不覆盖现有连接。保存时重新检查配置，在单个 SQLite 事务内写入，失败全部回滚；导入与预览都不会尝试连接远程数据库。

验证：新增 10 项测试覆盖 XML 实体与中文、引擎映射、密码及预览不泄露密码、不兼容设置、无效端口、NexSQL JSON、损坏 XML / DTD 拒绝、去重和 SQLite / Redis 参数。真实 SQLite 持久化测试结合 safeStorage 替身，验证加密流程、选区导入、并发去重、全批回滚。完整测试 81 项通过，9 项远程测试因未配置连接跳过；renderer/main 类型检查与构建通过。隔离 UI 实测 UTF-16 NCX、勾选导入、重复文件与错误文件恢复。尚未使用用户实际导出的 NCX 文件验收不同 Navicat 版本的格式差异。

兼容性修复：原解析器将 `<Connection>` 内所有非空子节点视为文件结构错误，导致一条连接阻断整份文件。现兼容数据库 / Schema 显示列表、已知标量子字段及空 CDATA；显示列表不用于推断初始数据库。未知子配置仅将该连接标记为不支持，属性与子字段冲突仅将该连接标记无效，其余连接保持可预览和勾选。提示只显示子标签名，不输出其配置值，界面移除 Electron IPC 的内部错误前缀。新增 4 项回归测试，涵盖混合自闭合连接、显示列表、子字段密码、未知隧道子配置和字段冲突；完整测试 85 项通过、9 项远程测试跳过。用户提供的单条结构为可识别的自闭合连接，尚未拿到整份报错文件确认具体触发的子节点。


## SSH 隧道（2026-10-15）

连接配置支持 SSH 密码认证和私钥认证（包括带口令的 RSA / OpenSSH Ed25519 私钥）。数据库主机名由跳板机解析，数据库浏览、查询工作进程和取消执行的控制连接均通过隧道转发；连接仅监听本机回环地址。取消握手、超时、窗口销毁、断开或查询结束会清理对应资源，取消单条查询不会关闭其他查询的隧道。Redis 浏览、键详情与删除同样支持隧道。MySQL / PostgreSQL / Redis / SQL Server 已接入，SQLite 不适用。

首次连接使用原生确认窗口展示 SHA256 主机指纹，接受后记录在应用数据目录的 `ssh-known-hosts.json`；指纹发生变化时拒绝连接。SSH 密码和私钥口令通过现有系统凭据加密机制保存，旧明文字段在启动时迁移；列表、导出和导入预览不返回秘密值。编辑时留空保留已保存的凭据，切换认证方式清理另一种凭据。

Navicat NCX 和 NexSQL JSON 导入保留 SSH 主机、端口、用户名、认证方式及私钥路径，兼容扁平字段和嵌套 SSH 节点；支持识别的 NCX 加密密码 / 私钥口令。无法恢复的凭据和需要在新电脑调整的私钥路径会明确提示，未知认证方式禁止导入。尚不支持 SSH Agent、多跳及多因素交互认证。

验证：完整 112 项测试通过，另补充加密 OpenSSH Ed25519 密钥及经过 SSH 的 MySQL TLS / 取消执行测试，2 项通过。实库覆盖 MySQL、PostgreSQL、Redis 的结构浏览、事务、错误后继续执行、独立连接取消长查询和并发隔离；同时覆盖转发、认证失败、指纹校验、握手取消、凭据持久化及导入去重。renderer/main 类型检查与构建通过，界面验证密码 / 私钥切换及保存。SQL Server 未做实库验证；Windows 安装包在 macOS 交叉构建，未在 Windows 系统运行验收。

### Navicat Redis 单机连接兼容修复（2026-10-15）

针对 `ConnType="REDIS" Type="Standalone"` 导出结构，允许空的 `<SentinelAddr Host="" Port="0"/>` 和叶节点 `<Profile ProfileName="AddressList" .../>`，并提示采用主连接配置。AddressList 中保存的 localhost、端口和认证配置不会覆盖主连接，子配置中的凭据不会出现在预览。非空 Sentinel 地址、未知 Profile 或嵌套子结构仍按连接逐条拒绝；Sentinel / Cluster 拓扑显示明确的不支持说明。

Redis `AuthenticationMode="Password"` 仅迁移密码，不使用 Navicat 默认写入的 `UserName="default"`，避免被现有阿里云账户认证逻辑错误拼为 `default:password`；`None` 模式不迁移闲置凭据。不能转换的加密密码允许导入并提示重新填写，绝不将密文当作密码。未知认证方式不静默降级。

新增 6 项回归测试，导入测试共 23 项通过；覆盖真实 SQLite 保存、凭据加密与重复导入，以及从 NCX 到 Redis 驱动认证参数的链路。完整测试 120 项，其中 105 项通过、15 项外部数据库测试因本次未配置实库而跳过；renderer/main 类型检查和构建通过。本次未连接用户提供的数据库地址。

## 连接侧栏布局与搜索（2026-10-15）

连接列表和数据库结构改为上下两个独立滚动区域，默认比例为 35% / 65%。标题及各自的搜索框不随内容滚动；分隔线支持拖动、键盘微调、Home / End 调整至边界和双击复位。使用现有 react-resizable-panels 保存比例，按可用高度约束连接区与结构区的最小高度，连接数量不再把数据库结构推到页面底部。无已连接数据库时保留结构区并显示连接提示。

新增固定连接搜索框，按连接名、主机、端口、分组、标签及 SQLite 路径本地筛选，大小写与全角字符归一化，空格分隔的多词需同时匹配。连接行展示地址和端口，筛选显示匹配数 / 总数，提供无结果提示和清空入口。方向键移动焦点，Enter 仅选中连接，Esc 清空并回到搜索框；双击保留连接行为，单击、搜索及筛选不发起连接，也不改绑查询标签的连接和数据库。

分组可折叠并本地保存；搜索期间自动展开匹配分组，清空后恢复原折叠状态。搜索词在切换侧栏标签时保留，重启后不恢复。列表行操作在悬停或键盘焦点时显示，操作按钮不触发连接行的选择 / 双击事件。

验证：新增 3 项搜索测试，覆盖多字段、多词、Unicode / 大小写、源顺序不变、凭据不参与搜索和端点显示。完整测试 123 项，108 项通过、15 项外部数据库测试跳过，无失败；renderer/main 类型检查及构建通过。隔离 SQLite 预览配置 121 个连接，实测独立滚动、固定搜索、搜索后恢复折叠、键盘选择、无结果状态、拖动与最小高度、双击复位以及重载后的布局 / 折叠持久化；搜索和切换连接时原 SQL 标签仍可查询 SQLite，数据库树保持可用。未连接任何用户业务数据库。

## 数据库与表分层搜索（2026-11-02）

数据库结构顶部的固定输入框改为“搜索数据库”，只在已连接连接的数据库目录中筛选库名，未展开数据库时也可使用。展开某个库后，在该库节点下面显示带库名的表搜索框，只筛选这个库已加载的表。两层条件独立，支持大小写及全角字符归一化，空格分隔的多词同时匹配。

切换或收起数据库会清空旧表筛选，收起连接会同步清除该连接的展开库状态；数据库搜索隐藏当前展开库时也会收起并清理其筛选，避免顶部文案与可见树节点的范围不一致。数据库搜索显示各连接的匹配数量和无结果提示，支持清空 / Esc；表搜索也有独立清空入口。

验证：renderer/main 类型检查与构建通过，查询状态和 SQL 传输相关 20 项测试通过，包含 100 库目录不触发表查询的回归测试。隔离 SQLite 示例实测 main、tenant_a、tenant_b：库名搜索不匹配表名，库内表过滤不会改动库名条件，切库 / 收起连接后无旧条件残留；请求日志仅包含目录读取以及两个库各一次的首次展开读取，输入搜索词和再次展开缓存库不额外请求表清单。
